# Data provenance

`wolfcamp_wells.csv` was copied from the user's supplied ZIP entry
`practicum/env_csv-Wells-6e675_2024-08-31.csv` (historical Enverus export).

The project owner confirmed on November 16, 2026 that this dataset may be shared
with the midterm submission. Include `data/raw/wolfcamp_wells.csv` in the project
repository. Reviewers can clone or download the repository and run the notebook
and training script against this file without a separate data download.

The training script intentionally does *not* use already encoded/imputed CSVs,
as they can leak validation information.
